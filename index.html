Before you start

Phase 1 · Before you start

01

The model

Who you talk to, and who actually writes the code.

Claude Code

Coding model · Anthropic

Reads, writes and runs code directly in your terminal, with your whole project folder in view.

Choose whenyou want finished features built, not snippets to paste in yourself.

Codex

Coding model · OpenAI

OpenAI's equivalent. Writes and runs code for you in the terminal or in the cloud.

Choose whenyou already pay for ChatGPT and want the coding help in the same subscription.

Claude

Chat model · Anthropic

The chat model in your browser. Explains, plans and writes text.

Choose whenyou want to think out loud and understand the problem before any code exists.

ChatGPT

Chat model · OpenAI

The most widely used chat model. Strong at explaining and at writing text.

Choose whenyou want a second opinion, or you are already used to it.

Gemini

Chat & code · Google

Google's model, available both as chat and as a coding tool in the terminal.

Choose whenyou work inside Google's tools and want everything in one place.

02

Skills, MCP & plugins

Three ways to make the model sharp on your project instead of generic.

Skills

Instructions

Folders of written instructions the model loads only when the task calls for them.

Choose whenyou keep repeating the same explanation and want it written down once and for all.

MCP

Connections

A shared standard that lets the model reach real systems: your database, GitHub, a calendar.

Choose whenthe model needs live data or has to act in a system, not just write text about it.

Plugins

Packages

Skills, commands and MCP connections bundled so they install in one step.

Choose whenyou want someone else's finished setup instead of assembling it yourself.

03

The terminal

The black window where you actually run the coding models. This is where AI coding happens.

Windows Terminal

The window · Microsoft

The modern terminal window on Windows, with tabs and readable text.

Choose whenyou are on Windows. This is the one to open.

PowerShell

The shell · Microsoft

The language the terminal understands on Windows. Commands like cd and ls are PowerShell.

Choose whendefault on Windows. Worth knowing the name so you can tell the AI which shell you run.

WSL

Linux inside Windows

Runs a real Linux inside Windows, so instructions written for Mac and Linux work.

Choose whena guide's commands do not work on Windows, which happens often.

04

The editor

Where you see the files and read what the AI has changed.

VS Code

Editor · Microsoft

Free, and the one most guides assume you have. Opens a whole project folder at once.

Choose whenalmost always. Start here.

Cursor

Editor · Anysphere

VS Code rebuilt around AI, editing the code inside the editor itself.

Choose whenyou want the AI in the same window as the code rather than in a terminal beside it.

Phase 2 · What gets built

05

Language & framework

What the AI builds with. This is the choice that most changes how the project turns out.

HTML, CSS & JavaScript

No framework · "vanilla"

The three languages every browser understands on its own. Nothing to install, one file can be the entire site.

Choose whenthe site mostly shows things. Fastest to build, easiest to fix, and never breaks from an update.

React

Interface library · Meta

Builds interfaces from reusable pieces and redraws them itself when data changes.

Choose whenmuch on screen changes as you click, and the same piece appears in several places. Costs extra tooling to set up.

Node.js

Server runtime · OpenJS

Runs JavaScript on a server instead of in the browser. Not a rival to React, it works underneath.

Choose whensomething has to be saved, sent, or kept secret. Passwords and API keys can never live in the browser.

06

Design & interface

How it looks, not just what it does.

Tailwind CSS

Styling

Styling written as small classes straight in the markup instead of in a separate file.

Choose whenyou want AI to produce a consistent look. Models write Tailwind reliably.

shadcn/ui

Components

Finished buttons, dialogs and forms you copy into the project and then own yourself.

Choose whenyou build with React and want it to look finished without designing every part.

Figma

Design tool

Draw the interface before it is built, and hand the picture to the AI.

Choose whenyou know what it should look like and words are not getting you there.

Phase 3 · Onto the internet

07

Version control

Where the code is saved, with every earlier version kept.

GitHub

Code hosting · Microsoft

Saves the project and its whole history, so a bad change can always be undone.

Choose whenalways, from day one. It is also the safety net that makes it safe to let AI change files.

GitLab

Code hosting

The same idea as GitHub, and can be run on your own server.

Choose whenan employer requires it, or the code may not sit with Microsoft.

08

Hosting

Where the site actually runs so other people can reach it.

Vercel

Hosting

Connects to GitHub and publishes a new version every time you save.

Choose whenyou build with React or Next.js. Least setup of them all.

Cloudflare Pages

Hosting

The same idea, with a generous free tier and small server functions included.

Choose whenyou need a bit of backend without paying for a server.

Netlify

Hosting

The same job, and long the simplest option for plain HTML sites.

Choose whenthe site is static and you want it published in a minute.

09

Domain & DNS

The address people type, and the system that points it at your site.

Cloudflare Registrar

Domain

Sells domains at cost price, with no first-year discount that triples later.

Choose whenyou want a .com, .app or .dev and want to avoid renewal surprises.

Loopia

Domain · Sweden

Swedish registrar. Needed for .se, which Cloudflare does not sell.

Choose whenyou want a .se address.

DNS

The phone book

Translates the name into the server's number. A change can take a few hours to spread.

Choose whenalways worth knowing, because "it does not work yet" is usually just DNS not finished spreading.

Phase 4 · When the app grows

10

Database

Where the data lives once something has to be remembered between visits.

PostgreSQL

Database

The standard choice for real applications. Free, and handles almost anything.

Choose whenusers, orders, or anything that must not be lost.

SQLite

Database in a file

An entire database in a single file. Nothing to install or run.

Choose whensmall projects, or while you are trying things out. Can be swapped later.

Cloudflare D1

Hosted SQLite

SQLite run by Cloudflare, right next to your hosting.

Choose whenyou are already on Cloudflare and want to keep it to one supplier.

11

Login

Letting users have accounts without you storing passwords yourself.

Supabase

Login + database

Login and a Postgres database in one, built on open source.

Choose whenyou need both, and want to be able to move the data out later.

Firebase

Login + database · Google

Google's version. Very quick to start with, harder to move away from.

Choose whenyou want Google, Apple and email login working today.

Clerk

Login

Finished login screens you drop straight into a React project.

Choose whenlogin should look good without you building the screens.

Applies the whole way

Security & law

Not a step. These apply from the first line, and the AI will not raise them unless you do.

GDPR

Law · EU

EU rules for handling personal data. A name or an email address is already personal data.

Applies whenanything about a person is saved. IMY is the Swedish supervisory authority.

Cookie consent

Consent

Asking before you store cookies or start tracking. Declining must be as easy as accepting.

Applies whenyou add analytics or embed anything from another site. PTS supervises this in Sweden.

OWASP Top 10

Security list

The ten most common security mistakes in web applications, kept current by the industry.

Applies whenanything is about to go live. Ask the AI to review your code against the list first.
